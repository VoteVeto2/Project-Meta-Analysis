摘要

本探索性便利样本元分析综合了多智能体LLM编排与单智能体提示在基准准确率上的研究内比较（2023–2026年）。主要的项目级二项规格——37项准确率指标研究——给出 log-OR = 0.46, 95% CI [0.22, 0.71]（REML + HKSJ）；完整便利样本（k = 41，含四项胜率/解决率研究）给出 log-OR = 0.45 [0.23, 0.67]。在绝对尺度上，增益较小且依赖加权方式：聚合（精度加权）风险差约为3个百分点（未加权研究均值约为8 pp；聚合Cohen's h = 0.07，未加权为0.20）。该估计值脆弱：异质性极高（I² = 96.1%），预测区间跨越零点（[−0.74, 1.64]），Egger检验检测到漏斗图不对称（p = .024）。在计算资源对等条件下（k = 9），相对效应衰减（log-OR 0.31），但绝对增益并未缩小（聚合RD约为5 pp），因为对等子集省略了规模庞大、近乎零效应的通识知识基准。已定位来源/已验证子集（k = 10）给出更低的 log-OR = 0.35，且异质性大幅降低。由于76%的提取行缺乏独立验证（已审核行的50%错误率），且多数研究未控制计算量，这些发现仅为初步结果，属假设生成性质。

1. 引言

多智能体大语言模型范式基于一个引人注目的直觉：正如人类团队在复杂任务上优于个人，多个LLM实例通过结构化协议合作应该超越单个实例的表现。Du等 (2023) 的早期工作表明，多智能体辩论提高了ChatGPT的事实性和推理能力，Liang等 (2024) 则展示了多智能体讨论如何促进发散性思维。AutoGen (Wu等, 2023)、MetaGPT (Hong等, 2023) 和 ChatDev (Qian等, 2024) 等框架现已在层级结构、辩论和协作工作流中编排数十个专门化智能体。

然而，一种质疑叙事已经出现。Zhang等 (2025) 直接表明，多智能体辩论在消耗远多于单智能体的推理计算的情况下，往往无法超越思维链和自一致性等简单的单智能体基准线。随着前沿模型的改进，协调开销可能超过递减的边际收益。

据我们所知，目前尚无综合这些相互矛盾发现的定量元分析；我们的非穷尽检索未发现直接可比较的研究，尽管多智能体LLM综述和基准测试确实存在（Guo等, 2024）。个别研究在架构（辩论vs.层级vs.协作）、任务领域（代码vs.医学vs.数学）、骨干模型以及是否强制计算对等方面差异很大。这种异质性使叙述性综述不可靠。我们提出四个研究问题：

RQ1（主要）。多智能体LLM系统在基准准确率上是否优于单智能体基准线？
RQ2（计算对等）。在匹配的计算预算下，多智能体优势是否存在？
RQ3（前沿悖论）。随着基线单智能体准确率的提高，编排增益是否缩小？
RQ4（调节变量）。哪些任务和架构属性预测效应方向？

2. 方法

2.1 搜索策略与局限

我们部署了六个并行搜索智能体，覆盖不同主题集群：多智能体辩论、协作/层级架构、软件工程和代码生成、医学/科学推理、批判性和零结果文献、以及前沿模型比较。每个智能体查询了arXiv、ACL Anthology、NeurIPS/ICML/ICLR论文集和Google Scholar，目标为2023–2026年的论文。共检索到153条记录。搜索字符串见附录C。

重要注意事项：这是一个便利样本，不是注册的系统综述。未预注册任何方案。搜索策略虽然广泛，但不能保证详尽覆盖。六智能体方法引入的选择偏差与人工系统搜索不同但未必更好。结果应视为假设生成性质。

2.2 筛选与纳入（PICOS）

研究对象：2023–2026年实证LLM研究。干预：任何多智能体编排（辩论、协作、层级、角色扮演、验证-批评、混合智能体、计划-执行）。对照：使用相同骨干模型的单智能体基准线。结果：命名基准上的准确率或成功率比例。研究设计：研究内面对面比较。仅纳入在同一基准上报告可比较MA和SA结果、使用相同或明确可比较骨干模型的研究。

排除标准：经典多智能体强化学习、无实证结果的立场论文、缺乏单智能体对照的研究、仅模拟评估。去重（去除26条）和PICOS筛选（排除21条）后，剩余106条记录。其中41条报告了多智能体和单智能体条件下可提取的准确率数据。65条被排除的记录详见附录D。筛选由作者在AI辅助下完成；未计算正式的评估者间一致性，这是一个局限。

剩余风险。29个未审核行（71%）可能包含类似错误，且41个分母中有30个为推算而非论文确认。已定位来源/仅已验证的敏感性分析（k = 10，第3.5节）是合并估计值最可信的锚点。

2.4 效应量

我们计算对数优势比（log-OR）作为主要效应量。由于无法获得项目级配对正确性数据，MA和SA的比例被视为独立二项计数。当两臂为逐项配对（同一组基准项目在两种条件下评分）时，忽略两臂间的正相关会高估各研究的研究内方差，因而是保守的；胜率和解决率研究并非逐项配对。整体不确定性的真正低估反而源于效应量之间的依赖性（每篇论文、每个基准或每个模型系列的多重比较；见§2.5）。仅对存在零单元格的研究有条件地应用0.5连续性校正（Sweeting等, 2004）；本样本中不存在此情况。对每项研究，我们提取 n-items（基准题目总数）、多智能体条件下的 n-correct 和单智能体条件下的 n-correct。当 n-items 无法直接提取时，将其设为基准的标准大小或根据报告的百分比估计。按计算的 n-items-provenance 轴，41个分母中仅10个为论文审核；30个为基准推算，1个为百分比估计（v6字段标记了28个"精确"，但该字段将论文确认与假定的基准大小混为一谈）。完整提取表见附录表A1。

风险差近似。为便于实际解读，我们报告风险差（RD = pMA − pSA），在流水线内计算（src/effect_sizes.pooled_absolute_effect）。RD依赖加权方式：全部41项研究的聚合（精度/n加权）RD约为3 pp，但未加权研究均值约为8 pp（中位数6 pp）。在计算对等条件下聚合RD约为5 pp——相对于全样本它没有缩小（§3.4）。Log-OR保留为正式效应量；相对（log-OR）尺度与绝对（RD）尺度在各子集间的分歧本身就是不应过度解读任何单一绝对数字的理由。

指标异质性与主要规格。41项比较包括项目级准确率（37项）、一项胜率和三项解决率。AlpacaEval 2.0（S040）是一项由LLM标注者评判、针对GPT-4参考的长度受控成对胜率——并非逐项二项准确率——而SWE-bench研究（S009、S010、S025）报告问题解决率。将这四项视为二项比例是一种简化，因此主要规格为37项项目级准确率研究（k = 37，log-OR = 0.46 [0.22, 0.71]）；完整的 k = 41 作为稳健性纳入报告。二者在数值上无法区分。

2.5 统计模型

主要分析使用限制最大似然（REML）随机效应模型（Viechtbauer, 2005），配合修正的Hartung-Knapp-Sidik-Jonkman（HKSJ）调整（Hartung & Knapp, 2001；IntHout等, 2014）。HKSJ调整计算缩放因子 s²HK = Σwi(yi − μ)²/(k−1)，并应用 max(1, s²HK) 作为方差膨胀下限，遵循HKSJ相对于朴素逆方差估计绝不应缩窄CI的保守建议（Röver等, 2015）。CI使用 t(k−1) 自由度。预测区间使用 t(k−2)（IntHout等, 2016）。DerSimonian-Laird估计作为敏感性检验。Cochran's Q使用固定效应权重和固定效应合并均值计算，得到在各方差估计量间一致的单一Q值（Borenstein等, 2009，第16章）。

亚组分析对每一水平使用独立的随机效应模型，Qbetween 通过Q分割法计算（Qbetween = Qtotal − ΣQwithin；Borenstein等, 2009，第19章）。单例类别（任务中factuality k=1；架构中moa和planner-executor各k=1）被合并到最近的"其他"类别，使所有亚组表合计为 k = 41。元回归为混合效应模型，采用条件REML τ² 估计和Knapp-Hartung t 分布推断（Viechtbauer, 2010）。逐一剔除敏感性分析每次迭代重新估计 τ²。

依赖性。多个效应量有时来自同一论文、基准系列或模型系列。本版本未实施稳健方差估计（Hedges等, 2010；Pustejovsky & Tipton, 2022）或多层元分析（Van den Noortgate等, 2013）。非聚合敏感性分析（k = 36）部分解决但未完全消除该局限。

2.6 偏倚风险

我们进行了基于ROB 2概念改编的非正式偏倚风险评估（Sterne等, 2019），涵盖选择、性能/计算对等、报告和损耗领域。这不是针对LLM基准研究的经过验证的工具；应理解为结构化质量检查清单。41项研究中25项（61%）被评为高偏倚风险，主要因为未控制计算量：多智能体系统通常消耗更多推理token，却没有任何单智能体扩展比较。在41个提取行中，仅10个经过独立验证（4个已验证，6个已验证并更正）；2个不可验证（无法定位来源数据）；29个仍未审核。在12个已审核行中，6个需要更正（50%错误率）。由于41行中有31行（76%）缺乏独立验证，合并估计值很大程度暴露于提取错误。

2.7 发表偏倚

作为探索性发表偏倚诊断，我们进行了漏斗图检查、Egger回归检验（Egger等, 1997）、Begg秩相关（Begg & Mazumdar, 1994）和Duval-Tweedie剪补法（Duval & Tweedie, 2000）。这些方法在极端异质性（I² > 90%）下不可靠，因为漏斗图不对称可能反映真实异质性或小研究效应而非发表偏倚本身（Egger等, 1997）。

3.2 描述性特征

41项纳入比较涵盖2023–2026年。主要架构为辩论（k = 20, 49%），其次为协作（k = 9）、层级（k = 6）、验证-批评（k = 2）、角色扮演（k = 2）和其他/稀有（k = 2，包含一项混合智能体和一项计划-执行研究）。任务类别包括代码生成（k = 11）、其他/混合（k = 11，含一项从单例类别合并的事实核查研究）、医学推理（k = 7）、数学（k = 6）、评估任务（k = 3）和通识知识（k = 3）。骨干模型涵盖GPT-4变体、Claude、Gemini、Qwen和开源模型。按计算的来源出处轴，41个分母中仅10个为论文审核（30个基准推算，1个百分比估计）。仅9项研究强制计算对等。完整提取表见附录表A1。

全样本的正式效应量为 log-OR = 0.45 (95% CI [0.23, 0.67], p < .001)，主要的仅准确率子集（k = 37）为 0.46 [0.22, 0.71]，对应 OR ≈ 1.57。在绝对尺度上，增益较小且依赖加权方式：聚合（精度/n加权）风险差约为3 pp（Cohen's h = 0.07），而未加权研究均值约为8 pp（平均 h = 0.20，恰好处于0.20的"小"效应边界；Cohen, 1988）。聚合数字被规模庞大、近乎零效应的通识知识基准（如MMLU，n = 14,042）拉低；加权与未加权汇总之间的差距本身就是极端异质性的征兆。每100道题多答对几道是否值得增加的复杂性和计算成本，是系统设计问题，不是统计问题。

关键警告：主要局限不是随机效应模型，而是提取表的质量和可审计性。合并效应为正但脆弱： (1) 预测区间 [−0.74, 1.64] 跨越零点，因此新研究有可能发现单智能体占优。 (2) Egger检验显著（p = .024），表明漏斗图不对称及可能的发表偏倚或小研究效应。 (3) 绝对增益较小（聚合Cohen's h = 0.07；未加权研究均值0.20）。 (4) 61%的研究为高偏倚风险，76%的行未经独立验证。 (5) I² = 96.1% 意味着"平均效应"作为点预测几乎没有意义。

3.4 计算对等：最重要的敏感性分析

在计算对等条件下（k = 9），相对效应衰减约31%（log-OR = 0.31, 95% CI [0.006, 0.61]）；CI下限仅勉强脱离零点，因此在略有不同的样本下相对结论会反转。然而在绝对尺度上，对等子集并未缩小：其聚合RD约为5 pp（Cohen's h ≈ 0.11），大于全样本的约3 pp，因为对等研究恰好排除了稀释全样本聚合值的规模庞大、近乎零效应的通识知识基准。两种尺度发生分歧，而这种分歧——而非单一的"约2 pp"数字（v6错误地报告了这一数字）——才是诚实的结论：在公平的计算比较下，相对的多智能体优势是脆弱的，而绝对增益虽小但依赖尺度和子集。

3.5 已验证子集作为可信度锚

已定位来源/已验证子集（k = 10——其主要来源被独立定位且报告比例经交叉核对的研究）给出 log-OR = 0.35 [0.19, 0.51]，明显低于全样本，异质性大幅降低（τ² = 0.01 vs. 0.34）。较低的点估计是一个警告：31个未验证行可能包含使合并效应膨胀的提取错误。τ² 的降低表明全样本中部分表观异质性来自提取噪声而非真实的研究间变异。

3.6 异质性

异质性极端：I² = 96.1%，Q(40) = 1016.6 (p < .001)，τ² = 0.34，τ = 0.58。研究间标准差（τ = 0.58）超过合并估计值本身（0.45），确认真实效应分布很宽。合并均值不应作为任何特定场景的点预测。

4. 讨论

4.1 主要发现

多智能体LLM系统平均似乎优于单智能体基准线（RQ1；log-OR = 0.45 全样本 / 0.46 仅准确率），但绝对边际较小：每100道题聚合约多3个正确答案（Cohen's h = 0.07），按未加权研究均值约多8个（h = 0.20）。预测区间 [−0.74, 1.64] 跨越零点，意味着多智能体优越性在任何新场景中并非必然。对许多应用而言，这可能不足以证明增加的基础设施复杂性和推理成本的合理性。

Egger检验（p = .024）表明该估计值很可能被小研究效应或发表偏倚所膨胀。已验证子集（k = 10, log-OR = 0.35）提供了最可信的锚点：它显示更小的效应和显著更低的异质性，表明提取噪声可能同时膨胀了估计值和表观研究间变异。

4.2 多智能体可能在何时有效？

亚组分析暗示一个描述性模式，但非因果结论。代码生成（log-OR = 0.83）可能受益于软件工程固有的模块性：生成代码、编写测试、审查和调试对应于不同的智能体角色（Hong等, 2023；Zhang等, 2024）。医学推理（log-OR = 0.42）可能受益于角色专门化专家智能体之间的协作式多轮共识（Tang等, 2024）。通识知识无效益（log-OR = 0.02）。但这些亚组差异与计算分配、骨干模型和研究质量存在混淆。

4.3 计算混淆

在计算对等条件下，相对效应缩小约31%（0.45→0.31），因此在相对尺度上优势在公平比较下勉强存活；然而在绝对尺度上，对等子集的聚合RD（约5 pp）并未低于全样本（见§3.4），故衰减是尺度特异的。消耗5倍单智能体token的多智能体辩论，应与给予相同token预算、通过思维链、自一致性或重复采样的单智能体进行比较。Zhang等 (2025) 恰恰证明了这一点——在同等或更多推理计算下，多智能体辩论往往无法击败单智能体思维链和自一致性。（更具体地说，Sprague等 (2024) 发现思维链的增益集中于数学和符号推理——这提醒我们推理时策略具有领域特异性。）相对的多智能体优势在计算均等化后勉强存活，削弱了将编排作为通用默认方案的实际论据。

4.4 局限性

数据质量局限。第一，这是探索性便利样本元分析，非注册系统综述。65条无可提取数据的被排除记录可能并非随机缺失（附录D）。第二，Egger检验显著（p = .024），表明发表偏倚或小研究效应。第三，61%的研究为高偏倚风险（主要因未控制计算量），仅10/41行经过独立验证（76%未验证），更正率为50%。第四，I² = 96.1%极端；合并均值作为点预测几乎没有意义。第五，指标异质性（准确率、pass@1、胜率、解决率）意味着log-OR模型假定的同质性高于底层数据所能提供的。第六，由于无法获得项目级配对正确性，MA和SA比例被视为独立二项计数；当两臂为逐项配对时，这会高估研究内方差（保守），故不会低估不确定性——整体不确定性的低估反而源于第七条局限所述的效应量间未建模依赖性。

分析局限。第七，效应量间的依赖性未正式建模；严格推断需要稳健方差估计（Hedges等, 2010）或多层建模（Van den Noortgate等, 2013）。第八，所有亚组分析均为探索性且未校正多重比较。第九，元回归中无调节变量显著，但该回归检验力不足。

5. 结论

本项目不能证明多智能体LLM系统普遍优于单智能体基准线。它表明当前便利样本中存在一个小的正向平均效应（log-OR = 0.45 全样本 / 0.46 仅准确率；聚合RD约3 pp，Cohen's h = 0.07），但证据高度不确定：异质性极端，预测区间跨越零点，绝对效应小且依赖加权方式，检测到发表偏倚，且大多数提取行未经验证。在计算对等条件下，相对效应衰减至 log-OR 0.31（统计上边缘显著），尽管绝对风险差并未缩小。

最具实践意义的结论是：在声称协同效应之前，多智能体系统应与计算匹配的单智能体基准线进行比较。多智能体编排可能在可分解、可验证的任务（代码生成、医学推理）中、在计算预算充足时有帮助，但证据基础污染过重，不足以支持强主张。该领域迫切需要计算控制的比较、独立提取审计和注册元分析。

根据鲁汶大学关于在教育中使用人工智能的政策（第84条），本工作中使用了以下AI工具：

  • 文献搜索：部署六个Claude Code智能体并行搜索arXiv、ACL Anthology和会议论文集。每个智能体覆盖一个独立主题集群。所有检索记录均按PICOS标准人工筛选。未计算评估者间筛选一致性。
  • 数据提取和验证：Claude Code智能体协助从原始来源进行初步数据提取。独立智能体对41项研究中的12项进行了第二编码者验证遍：4项已验证，6项需更正（50%错误率），2项不可验证。其余29项研究未审核；总计41行中有31行（76%）缺乏独立验证。
  • 统计分析：所有统计计算（效应量、合并、元回归、发表偏倚检验）使用Python开源库实现。代码见 src/。
  • 报告撰写：Claude Code协助起草和构建HTML报告。所有统计解读、批判性评估和结论均由作者审核和验证。
  • 修订：Claude Code协助实施针对同行评审的修正。v3解决50个问题；v4解决7个小问题；v5解决20个问题；v6解决10个重大问题；v7解决了v6评审的全部11个发现——突出仅准确率规格、使绝对效应指标在流水线内可重现、为纳入研究添加完整参考文献（附录G）、更正Guo/Sprague/MedAgents引用，并理顺验证轨迹（见 report/review/）。
  • 使用模型：Claude Opus 4.6（v3–v6）和 Claude Opus 4.8（v7），通过Claude Code (Anthropic)。

附录E：Cohen's h 作为次要效应量

Cohen's h = 2 arcsin(√pMA) − 2 arcsin(√pSA) 提供绝对尺度效应量，对基础率膨胀的敏感度低于log-OR。在高准确率区间（两种条件均>90%）下，微小的比例差异会产生很大的log-OR却只有很小的 h。基准：0.20 = 小，0.50 = 中，0.80 = 大（Cohen, 1988）。v7 注：下表为聚合（比例求和）h——可直接重现的合并值，由 src/effect_sizes.pooled_absolute_effect 输出。各研究 h 的未加权均值更高（全样本为0.20）；报告突出聚合值，但同时报告二者，因为它们之间的差距反映了 I² = 96% 的异质性。
