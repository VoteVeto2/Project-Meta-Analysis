More Agents, Better Results? A Meta-Analysis of Multi-Agent vs Single-Agent LLM Systems

Xinyu Yang (r1020926)
KU Leuven, Faculty of Psychology and Educational Sciences
Meta-Analysis (G0B75a), Academic Year 2025–2026
22 May 2026 — Revision 2 (post peer review)

Abstract

This exploratory convenience-sample meta-analysis synthesizes 41 within-study comparisons (2023–2026) of multi-agent LLM orchestration (debate, cooperation, hierarchical delegation) versus single-agent prompting on benchmark accuracy. Under a REML random-effects model with Knapp-Hartung adjustment, the pooled log-OR favored multi-agent systems (log-OR = 0.45, 95% CI [0.25, 0.65], p < .001), corresponding to a small-to-moderate advantage (OR = 1.57). Heterogeneity was extreme (I² = 96.1%, τ² = 0.34, Q(40) = 1016.6), and the 95% prediction interval spanned zero ([−0.74, 1.64]), indicating that a new study could plausibly find single-agent superiority. Subgroup analysis revealed that the advantage concentrates in code-generation tasks (log-OR = 0.83) and hierarchical architectures (log-OR = 0.76), while general-knowledge tasks showed no benefit (log-OR = 0.02). Under compute parity (k = 9), the effect attenuated to log-OR = 0.31 [0.04, 0.57]. Sensitivity analyses restricted to verified studies (k = 12: log-OR = 0.45 [0.26, 0.64]) and non-aggregated benchmarks (k = 36: log-OR = 0.48 [0.24, 0.72]) confirmed the main finding. Meta-regression using baseline single-agent accuracy as a frontier-paradox proxy found a directionally consistent but non-significant effect (β = −0.77, t(32) = −1.38, p = .176). Publication bias diagnostics (Egger p = .77; p-curve: 25/28 significant results right-skewed, p < .001) indicated genuine evidential value. As an unregistered convenience sample, these findings should be interpreted as hypothesis-generating rather than confirmatory.

1. Introduction

The multi-agent paradigm for large language models rests on a compelling intuition: just as human teams outperform individuals on complex tasks, multiple LLM instances collaborating through structured protocols should exceed what a single instance achieves alone. This intuition has fueled rapid adoption. Frameworks such as AutoGen (Wu et al., 2023), MetaGPT (Hong et al., 2023), and ChatDev (Qian et al., 2024) now orchestrate dozens of specialized agents in hierarchies, debates, and cooperative workflows.

Yet a skeptical counter-narrative has emerged. Sprague et al. (2024) and Chen et al. (2025) argue that much of the observed multi-agent advantage dissolves once compute is equalized — multi-agent systems simply consume more inference tokens. Lu et al. (2024) demonstrated that scaling a single agent's sampling budget can match or exceed multi-agent debate. And as frontier models improve — Claude Opus 4.5, GPT-4o, Gemini 2.5 — the coordination overhead may outweigh diminishing marginal gains (Anthropic, 2025).

No meta-analysis has yet synthesized these conflicting findings. Individual studies vary in architecture (debate vs. hierarchy vs. cooperation), task domain (code vs. medical vs. math), backbone model, and whether compute parity is enforced. This heterogeneity makes narrative reviews unreliable. We address four research questions:

RQ1 (Primary). Do multi-agent LLM systems outperform single-agent baselines on benchmark accuracy?
RQ2 (Compute parity). Under matched compute budgets, does the multi-agent advantage survive?
RQ3 (Frontier paradox). As baseline single-agent accuracy increases, does the orchestration gain shrink?
RQ4 (Moderators). Which task and architecture properties predict effect direction?

2. Methods

2.1 Search strategy

We deployed six parallel search agents covering distinct topic clusters: multi-agent debate, cooperative/hierarchical architectures, SWE and code generation, medical/scientific reasoning, critical and null-result literature, and frontier-model comparisons. Each agent queried arXiv, ACL Anthology, NeurIPS/ICML/ICLR proceedings, and Google Scholar, targeting papers from 2023–2026. This yielded 153 records across all agents.

2.2 Screening and inclusion (PICOS)

Population: Empirical 2023–2026 LLM studies. Intervention: Any multi-agent orchestration (debate, cooperation, hierarchy, role-play, verifier-critic, mixture-of-agents, planner-executor). Comparator: Single-agent baseline using the same backbone model. Outcome: Accuracy or success-rate proportion on a named benchmark. Study design: Within-study head-to-head comparison.

Exclusions: classical multi-agent reinforcement learning, position papers without empirical results, studies lacking a single-agent comparator, and simulation-only evaluations. After deduplication (26 removed) and PICOS screening (21 excluded), 106 records remained. Of these, 41 reported extractable accuracy data for both multi-agent and single-agent conditions.

2.3 Effect size

We computed log odds ratios (log-OR) as the primary effect size. A 0.5 continuity correction was applied conditionally, only to studies with zero cells (Sweeting et al., 2004). In the present sample, no study contained zero cells, so the correction was not applied. For each study, we extracted n-items (total benchmark questions), n-correct under multi-agent, and n-correct under single-agent conditions. Where n-items could not be extracted directly, it was estimated from reported percentages and total benchmark sizes; 18 of 41 studies are flagged as estimated in the data file. Cohen's h was computed as a secondary effect size and is reported in Appendix C.

2.4 Statistical model

The primary analysis used a restricted maximum-likelihood (REML) random-effects model (Viechtbauer, 2005) with the Hartung-Knapp-Sidik-Jonkman (HKSJ) adjustment for confidence intervals (Hartung & Knapp, 2001; IntHout et al., 2014). CIs use t(k−2) instead of z = 1.96. Prediction intervals follow IntHout et al. (2016), using t(k−2). DerSimonian-Laird estimation served as a sensitivity check. Cochran's Q is computed using fixed-effect weights and the fixed-effect mean, yielding a single Q value that is identical across estimators (Borenstein et al., 2009, Ch. 16).

Subgroup analyses used separate random-effects models per level with between-group Q computed via the partition-of-Q approach (Qbetween = Qtotal − ΣQwithin; Borenstein et al., 2009, Ch. 19). Meta-regression was mixed-effects with conditional REML τ² estimation and Knapp-Hartung t-distribution inference, reporting the omnibus QM test (Viechtbauer, 2010). Leave-one-out sensitivity analyses re-estimate τ² per iteration.

2.5 Risk of bias

We adapted the ROB 2.0 framework (Sterne et al., 2019) with domains for selection, performance/compute parity, reporting, and attrition. Each study was rated as "low risk," "some concerns," or "high risk." The most common source of high risk was uncontrolled compute: multi-agent systems typically consumed 3–10× more inference tokens without any single-agent scaling comparison.

2.6 Publication bias

Funnel plot inspection, Egger's regression test (Egger et al., 1997), Begg's rank correlation (Begg & Mazumdar, 1994), Duval and Tweedie's trim-and-fill (Duval & Tweedie, 2000), and p-curve analysis (Simonsohn et al., 2014) were conducted with k = 41.

The REML model yields a pooled log-OR of 0.45 (95% CI [0.25, 0.65], p < .001), representing a small-to-moderate advantage for multi-agent systems. Converting to an odds ratio (e0.45 = 1.57), multi-agent systems have roughly 57% higher odds of a correct response on average.

Key finding: The prediction interval crosses zero. The 95% prediction interval [−0.74, 1.64] means that a new study drawn from this population of settings could plausibly show single-agent superiority. The "average effect" of 0.45 is real but nearly meaningless as a point prediction given I² = 96.1%. The effect is not a stable property of multi-agent systems — it depends heavily on which task, which architecture, and how much compute is allocated.

3.4 Heterogeneity

Heterogeneity is extreme: I² = 96.1%, Q(40) = 1016.6 (p < .001), τ² = 0.34, τ = 0.58. The between-study standard deviation (τ = 0.58) exceeds the pooled estimate itself (0.45), confirming that the distribution of true effects is wide. This mandates subgroup and meta-regression analysis rather than reliance on the pooled mean.

The compute-parity sensitivity (k = 9) remains the most consequential: restricting to studies that equalized inference tokens reduces the pooled log-OR from 0.45 to 0.31 — an attenuation of roughly 31%. The effect remains significant (95% CI [0.04, 0.57]), suggesting that multi-agent orchestration provides value beyond mere compute scaling, but that uncontrolled compute confounding inflates the naive estimate. Removing high-RoB studies (k = 16) produces a nearly identical point estimate (log-OR = 0.42), and the 2025+ subset (k = 29) is also consistent (log-OR = 0.41).

Two new sensitivity analyses address data-quality concerns. The verified-only subset (k = 12) restricts to studies whose extracted data have been independently audited, yielding log-OR = 0.45 [0.26, 0.64] with substantially reduced heterogeneity (τ² = 0.05, down from 0.34). The close match to the full-sample estimate is reassuring, though the reduced τ² suggests that some heterogeneity in the full sample arises from extraction noise rather than genuine between-study variation. The non-aggregated subset (k = 36) excludes studies that averaged across multiple benchmarks, yielding log-OR = 0.48 [0.24, 0.72] — slightly higher than the full sample, indicating that aggregated-benchmark studies, if anything, attenuate the estimate.

5. Discussion

5.1 Principal findings

Multi-agent LLM systems do outperform single-agent baselines on average (RQ1: log-OR = 0.45, p < .001), but this statement requires immediate qualification. The prediction interval [−0.74, 1.64] is the headline result, not the pooled mean. It tells practitioners that the "average advantage" is a statistical artifact of averaging over radically different settings. For any specific deployment, the expected effect ranges from a moderate disadvantage to a large advantage, depending on task, architecture, and compute allocation.

5.2 When does multi-agent work?

The subgroup analyses provide actionable guidance. Code generation (log-OR = 0.83) benefits most, likely because software engineering is inherently modular: generating code, writing tests, reviewing, and debugging map naturally onto distinct agent roles (Qian et al., 2024; Zhang et al., 2024). Hierarchical architectures (log-OR = 0.76) align with this pattern — explicit task decomposition and delegation exploit the same modularity. Medical reasoning (log-OR = 0.42) benefits from adversarial verification, where a second agent challenges the first's diagnosis (Tang et al., 2024; Xiong et al., 2024).

Conversely, general-knowledge QA (log-OR = 0.02) derives no benefit. When a question has a single factual answer in the model's parametric knowledge, adding agents introduces coordination costs without new information. Cooperation without structure (log-OR = 0.31, CI crossing zero) fares similarly — unstructured multi-agent interaction often degenerates into echo chambers or sycophantic agreement (Du et al., 2023; Liang et al., 2024).

5.3 The compute confound and the frontier paradox

Under compute parity, the effect shrinks by ~31% (from 0.45 to 0.31). This is the most practically important finding for system designers. A multi-agent debate consuming 5× the tokens of a single agent should be compared not against a single call but against a single agent given the same token budget via chain-of-thought, self-consistency, or repeated sampling (Sprague et al., 2024; Lu et al., 2024). That the multi-agent advantage survives even after this adjustment (log-OR = 0.31, p < .05) suggests genuine emergent value in structured inter-agent communication — but practitioners should expect smaller gains than the headline numbers suggest.

The frontier-paradox hypothesis (RQ3) — that multi-agent gains shrink as baseline models strengthen — receives directional but inconclusive support. Replacing the previously used "year" proxy with baseline SA accuracy yields β = −0.77 (t(32) = −1.38, p = .176). The negative sign is consistent with the hypothesis: a one-unit increase in SA accuracy is associated with a 0.77 decrease in log-OR. However, at k = 41, the meta-regression is underpowered to detect a moderator of this magnitude. The question remains open and practically urgent as frontier models continue to improve.

5.4 Practitioner implications

The rise of agentic coding systems — Claude Code (Anthropic, 2025), Cursor, Devin — reshapes this discussion. These tools embed multi-agent patterns (planning, execution, verification) within a single-agent interface, making the MA-vs-SA distinction blurry. Our finding that hierarchical architectures and code tasks show the largest effects is consistent with these tools' design choices: they succeed precisely because software engineering has the task properties (decomposability, verifiability, modularity) that make multi-agent orchestration worthwhile.

5.5 Limitations

First, this is an exploratory convenience-sample meta-analysis, not a registered systematic review. Our six-agent search strategy, while broad, cannot guarantee exhaustive coverage, and the 65 studies excluded for lacking extractable data may not be missing at random. Second, the sample size (k = 41) limits meta-regression power; the null QM should not be interpreted as evidence of no moderation. Third, I² = 96.1% is extreme even by social-science standards, and while we explored moderators, substantial unexplained heterogeneity remains. Fourth, 61% of studies were rated high risk of bias, predominantly due to uncontrolled compute — a methodological weakness of the entire field, not just our sample. Fifth, 18 of 41 n-items counts were estimated rather than directly extracted, though the verified-only sensitivity (k = 12) confirms the main finding with sharply reduced heterogeneity (τ² = 0.05). Sixth, we did not model dependency among multiple effect sizes from the same paper via robust variance estimation (Hedges et al., 2010; Pustejovsky & Tipton, 2022); the non-aggregated sensitivity (k = 36) partially addresses this. Seventh, all subgroup analyses are exploratory and uncorrected for multiplicity.

5.6 What a full systematic review would add

A registered protocol with multiple independent coders, grey-literature search, and contact with primary authors would strengthen confidence in the estimate. Pre-registered moderator analyses would address the multiple-comparisons concern in our exploratory subgroup tests. Robust variance estimation (Hedges et al., 2010) or multilevel meta-analysis (Van den Noortgate et al., 2013) would permit multiple effect sizes per study without inflating Type I error.

6. Conclusion

This exploratory convenience-sample meta-analysis finds that multi-agent LLM orchestration confers a real but unstable advantage over single-agent baselines (pooled log-OR = 0.45, 95% CI [0.25, 0.65]). The prediction interval [−0.74, 1.64] is the finding that matters: it crosses zero, meaning multi-agent superiority is not guaranteed for any new setting. The advantage concentrates in code generation (log-OR = 0.83) and hierarchical architectures (log-OR = 0.76), evaporates for general-knowledge QA (log-OR = 0.02), and shrinks by 31% under compute parity (log-OR = 0.31). The verified-only subset (k = 12) confirms the main estimate with substantially reduced heterogeneity. The frontier-paradox hypothesis receives directional but non-significant support (β = −0.77, p = .176). Overall certainty of evidence is rated Low (GRADE), driven by pervasive risk of bias and extreme heterogeneity. Practitioners should deploy multi-agent systems selectively — for decomposable, verifiable tasks where structured agent roles add genuine information — and always benchmark against a properly scaled single-agent baseline. The field urgently needs compute-controlled comparisons: only 9 of 41 studies enforced parity.

Appendix A: Reproducibility

All analyses were conducted using Python 3.12 managed via uv. The full pipeline — from literature search to figure generation — is contained in the project repository. Key components:

  • Environment: pyproject.toml + uv.lock for deterministic dependency resolution. Reproduce with uv sync && uv run python main.py.
  • Data: Raw search results in data/raw/; extracted and verified effect-size tables in data/extracted/ and data/verified/. The n-items-estimated flag column indicates which studies have estimated rather than directly extracted item counts.
  • Analysis code: Reusable modules in src/ (effect_sizes, pooling, heterogeneity, moderators, publication_bias, sensitivity, plots). All logic is importable; notebooks call these modules.
  • Figures: All figures exported to report/assets/ with stable filenames.
  • Random seeds: Verification sampling used seed 42. All stochastic operations are seeded for reproducibility.

Appendix C: Cohen's h as Secondary Effect Size

Cohen's h was computed as 2 arcsin(√pMA) − 2 arcsin(√pSA) for each study, where pMA and pSA are the proportions correct under multi-agent and single-agent conditions, respectively. The table below summarizes pooled Cohen's h for key analyses under the REML random-effects model.

Table C1. Pooled Cohen's h (supplementary effect size).
AnalysiskCohen's hInterpretation
Full sample410.08Small effect

General knowledge30.00No effect

Cohen's h benchmarks: 0.20 = small, 0.50 = medium, 0.80 = large (Cohen, 1988). The small h values relative to the log-OR reflect that many studies operate in high-accuracy regimes where log-OR amplifies small proportion differences.
