更多智能体，更好结果？多智能体与单智能体LLM系统的元分析

杨新宇 (r1020926)
鲁汶大学，心理学与教育科学学院
元分析 (G0B75a)，2025–2026学年
2026年5月22日 — 第5版（终稿，经第4版审计后修订）

摘要

本探索性便利样本元分析综合了41项研究内比较（2023–2026年），评估多智能体LLM协同系统与单智能体提示方法在基准测试准确率上的差异。在采用完整Hartung-Knapp-Sidik-Jonkman校正的REML随机效应模型下，合并对数优势比为0.45，95% CI [0.23, 0.67]，p < .001（OR = 1.57；近似风险差≈ 3–5个百分点）。然而，该估计值并不稳健。异质性极高（I² = 96.1%，Q(40) = 1016.6），95%预测区间穿越零点（[−0.74, 1.64]），Egger检验发现显著的漏斗图不对称（p = .024），且总体Cohen's h效应量极小（h = 0.08）。在计算等价条件下（k = 9），效应减弱至log-OR = 0.31（h ≈ 0.05，可忽略不计）。元回归中无调节变量达到显著水平（QM(8) = 5.34，p = .72；R² = 0%）。亚组分析表明效应可能集中于代码生成任务和层级架构中，但组间检验（任务类别：Qbetween(5) = 197.56，p < .001；架构类型：Qbetween(4) = 32.75，p < .001）因未控制的混杂因素而需谨慎解读。鉴于61%的研究被评为高偏倚风险，41行数据中仅10行经过独立核实（76%未核实），且存在发表偏倚的证据，这些发现是初步的、仅具假设生成性质的。多智能体协同可能在计算资源充裕的可分解任务中有所帮助，但现有证据基础的质量不足以支撑强有力的结论。

1. 引言

大语言模型的多智能体范式建立在一个直觉上令人信服的假设之上：正如人类团队在复杂任务上优于个体，通过结构化协议协作的多个LLM实例应当超越单个实例的表现。Du等人（2023）的早期工作表明，多智能体辩论提高了ChatGPT的事实准确性和推理能力，而Liang等人（2024）展示了多智能体讨论能够促进发散性思维。AutoGen（Wu等人，2023）、MetaGPT（Hong等人，2023）和ChatDev（Qian等人，2024）等框架现已能够在层级结构、辩论和合作工作流中协调数十个专门化智能体。

然而，一种持怀疑态度的反叙事也已浮现。Sprague等人（2024）指出，一旦计算资源被均衡化，所观察到的多智能体优势便大幅消退——多智能体系统消耗更多的推理token，而扩大单智能体的采样预算可能达到同等性能。Zhang等人（2025）直接表明，在等量token预算下，单智能体基准线经常能够匹配甚至超越多智能体辩论。随着前沿模型不断改进，协调开销可能超过递减的边际收益。

目前尚无元分析对这些相互矛盾的发现进行综合。各研究在架构（辩论 vs. 层级 vs. 合作）、任务领域（代码 vs. 医学 vs. 数学）、骨干模型以及是否强制计算等价等方面存在差异。这种异质性使得叙述性综述不可靠。我们探讨四个研究问题：

RQ1（主要问题）。多智能体LLM系统在基准测试准确率上是否优于单智能体基准线？
RQ2（计算等价）。在匹配的计算预算下，多智能体优势是否依然存在？
RQ3（前沿悖论）。随着单智能体基准线准确率的提高，协同增益是否缩小？
RQ4（调节变量）。哪些任务和架构特征能预测效应方向？

2. 方法

2.1 检索策略及其局限性

我们部署了六个并行检索智能体，分别覆盖不同的主题集群：多智能体辩论、合作/层级架构、软件工程与代码生成、医学/科学推理、批判性与零结果文献，以及前沿模型比较。每个智能体在arXiv、ACL Anthology、NeurIPS/ICML/ICLR会议论文集和Google Scholar中进行检索，目标论文的发表时间为2023–2026年。共获得153条记录。检索字符串详见附录C。

重要说明：本研究为便利样本，并非注册的系统综述。未进行方案预注册。检索策略虽然广泛，但不能保证穷尽覆盖。六智能体方法引入的选择偏倚与手工系统检索不同，但未必更优。结果应视为假设生成性质的。

2.2 筛选与纳入标准（PICOS）

人群：2023–2026年的实证LLM研究。干预：任何多智能体协同方式（辩论、合作、层级、角色扮演、验证-批评、混合智能体、规划-执行）。对照：使用相同骨干模型的单智能体基准线。结局：命名基准测试上的准确率或成功率比例。研究设计：研究内的直接比较。

排除标准：经典的多智能体强化学习、无实证结果的立场论文、缺乏单智能体对照的研究以及仅含模拟评估的研究。经过去重（去除26篇）和PICOS筛选（排除21篇），剩余106条记录。其中41篇报告了多智能体和单智能体条件下的可提取准确率数据。被排除的65篇记录编目于附录D。筛选由作者在AI辅助下完成；未计算正式的评估者间一致性，这是本研究的一项局限。

2.3 效应量

我们以对数优势比（log-OR）作为主要效应量。仅对含零单元格的研究有条件地应用0.5连续性校正（Sweeting等人，2004）；实际中未出现此情况。对每项研究，我们提取了n-items（总基准测试题数）、多智能体条件下的n-正确数和单智能体条件下的n-正确数。当无法直接提取n-items时，根据报告的百分比和基准测试总量进行估算。在41项研究中，18项带有宽泛的n-items-estimated标记（任何形式的推导）；按来源质量更严格分类，有13项的分母为推算或估计值（k = 28为精确值）。第3.9节的敏感性分析采用更严格的定义。Cohen's h作为辅助效应量用于提供绝对尺度上的参考（详见附录E）。

风险差近似值。为便于实际解读，我们在对数优势比之外报告了近似风险差（RD = pMA − pSA）。全部41项研究的合并RD约为3–5个百分点，即多智能体系统每100题平均多答对约3–5题。在计算等价条件下，该值缩减至约2个百分点。

指标异质性。41项比较涵盖准确率、pass@1、胜率、可执行性分数和解决率等指标。我们将所有指标统一视为二项比例，但承认这一合并是一种简化。胜率基准（如AlpacaEval）与逐题准确率的基本假设不同；应在此限制下解读结果。

2.4 统计模型

主要分析采用限制性最大似然（REML）随机效应模型（Viechtbauer，2005），并进行修正的Hartung-Knapp-Sidik-Jonkman（HKSJ）校正（Hartung & Knapp，2001；IntHout等人，2014）。HKSJ校正计算尺度因子s²HK = Σwi(yi − μ)²/(k−1)，并应用max(1, s²HK)作为方差膨胀下限，遵循HKSJ不应使置信区间窄于朴素逆方差估计的保守建议（Röver等人，2015）。置信区间使用t(k−1)自由度。预测区间遵循IntHout等人（2016）使用t(k−2)自由度。DerSimonian-Laird估计作为敏感性检验。Cochran's Q使用固定效应权重和固定效应合并均值计算，得到跨方差估计器一致的唯一Q值（Borenstein等人，2009，第16章）。

亚组分析对每个水平使用独立的随机效应模型，Qbetween通过Q分割法（Qbetween = Qtotal − ΣQwithin；Borenstein等人，2009，第19章）计算。元回归采用混合效应模型，使用条件REML τ²估计和Knapp-Hartung t分布推断，报告综合QM检验（Viechtbauer，2010）。逐一剔除敏感性分析在每次迭代中重新估计τ²。

依赖性问题。多个效应量有时来源于同一论文、同一基准测试系列或同一模型系列。在本版本中，我们未实施稳健方差估计（Hedges等人，2010；Pustejovsky & Tipton，2022）或多层次元分析（Van den Noortgate等人，2013）。非聚合敏感性分析（k = 36）部分解决但未完全消除这一局限。

2.5 偏倚风险

我们改编了ROB 2.0框架（Sterne等人，2019），设置了选择偏倚、操作/计算等价、报告偏倚和失访偏倚等评估维度。在41项研究中，25项（61%）被评为高偏倚风险，主要原因是计算资源未控制：多智能体系统通常消耗更多推理token，而未进行任何单智能体扩展比较。在41行提取的数据中，仅10行经过独立核实（4行已核实，6行经核实后校正）；2行无法核实（无法定位源数据）；29行仍未审计。在已审计的12行中，6行需要校正（错误率50%）。由于41行中有31行（76%）缺乏独立核实，合并估计值受提取误差的影响较大。

2.6 发表偏倚

在k = 41的条件下进行了漏斗图检视、Egger回归检验（Egger等人，1997）、Begg秩相关检验（Begg & Mazumdar，1994）、Duval和Tweedie的剪补法（Duval & Tweedie，2000）以及p曲线分析（Simonsohn等人，2014）。

3.2 描述性特征

纳入的41项比较涵盖2023–2026年。主要架构类型为辩论（k = 20，49%），其次为合作（k = 9）、层级（k = 6）、验证-批评（k = 2）和角色扮演（k = 2），另有一项混合智能体研究和一项规划-执行研究。任务类别包括代码生成（k = 11）、"其他"混合基准测试（k = 10）、医学推理（k = 7）、数学（k = 6）、评估任务（k = 3）、通用知识（k = 3）和事实性验证（k = 1）。骨干模型涵盖GPT-4系列、Claude、Gemini、Qwen和开源模型。在41项研究中，18项的n-items值为估算而非直接提取。仅9项研究在多智能体与单智能体条件之间强制实施了计算等价。

REML模型得到合并log-OR = 0.45（95% CI [0.23, 0.67]，p < .001），对应OR = 1.57。然而在绝对尺度上，总体Cohen's h仅为0.08——远低于"小"效应的0.20阈值（Cohen，1988）。约3–5个百分点的近似风险差意味着，多智能体系统在每100道基准测试题中大约多答对3–5题。这是否足以证明增加的架构复杂性和推理成本是合理的，是一个系统设计问题，而非统计问题。

关键警示：多重威胁削弱了该估计值。合并效应为正但脆弱： (1) 预测区间[−0.74, 1.64]穿越零点，因此一项新研究完全可能发现单智能体更优。 (2) Egger检验显著（p = .024），提示漏斗图不对称，可能存在发表偏倚或小研究效应。 (3) Cohen's h = 0.08在绝对尺度上极小。 (4) 61%的研究为高偏倚风险，76%的数据行缺乏独立核实。 (5) I² = 96.1%意味着"平均效应"作为点预测几乎没有意义。 诚实的解读是：这是一个积极但初步的信号，而非稳健的发现。

3.4 异质性

异质性极高：I² = 96.1%，Q(40) = 1016.6（p < .001），τ² = 0.34，τ = 0.58。研究间标准差（τ = 0.58）超过了合并估计值本身（0.45），证实真实效应的分布非常广泛。合并均值不应用作任何特定场景的点预测。

组间Q检验高度显著（Qbetween(5) = 197.56，p < .001），表明任务类别与效应量变异相关。Q分割法假设各亚组具有共同的τ²；鉴于组内I²从0%到99.7%不等，该假设可能被违反。代码生成产生了最大的多智能体效应（log-OR = 0.83），与模块化、可分解任务更有利于智能体专业化的直觉一致（Hong等人，2023；Zhang等人，2024）。医学推理显示中等效应（log-OR = 0.42），可能反映了对抗性验证的价值（Tang等人，2024）。通用知识基本无获益（log-OR = 0.02），表明对于简单的事实检索，协调反而增加噪声。然而，这些亚组估计受到架构、骨干模型和计算分配等混杂因素的干扰；表面上的任务梯度可能部分反映了这些相关因素。k < 5的亚组标记为"仅供描述"——少于五项研究时，τ²、预测区间和置信区间均无参考价值（Borenstein等人，2009，第17章）。医学推理是唯一预测区间不含零的亚组[0.08, 0.76]，提示该领域的正向信号较为稳健。

发表偏倚已成为一项重要关切。Egger回归检验（基于截距计算）显著（截距 = 2.53，t(39) = 2.34，p = .024），表明漏斗图存在不对称性，符合小研究效应特征——样本中较小的研究倾向于显示更大的正向效应。该模式是发表偏倚的典型特征（小样本正结果研究被发表，而小样本零结果研究则未被发表），也可能反映与研究规模相关的真实异质性。Begg检验和剪补法不显著，但这些方法对于连续结果的灵敏度低于Egger检验。P曲线显示右偏（25/28项结果显著），但p曲线假设独立、同质的假设检验——这些条件在此仅近似满足。总体而言，合并效应的正向估计可能因选择性报告而被高估，这从根本上削弱了主要发现。

最为关键的敏感性分析是计算等价（k = 9）：限制于均衡推理token的研究后，合并log-OR从0.45降至0.31（衰减约31%）。置信区间下限勉强脱离零（未取整：[0.006, 0.607]），对应的Cohen's h约为0.05——按常规标准可忽略不计。这意味着在公平的计算比较条件下，多智能体系统每100道基准测试题仅多答对约2题，该效应在统计上处于边界水平，在实践中微不足道。

仅核实过的子集（k = 10）明显低于全样本估计：log-OR = 0.35 [0.19, 0.51]，异质性急剧下降（τ² = 0.01 vs. 0.34）。较低的点估计值是一个警示：31行未核实的研究可能包含提取误差，从而推高了合并效应。τ²的降低表明全样本中的部分表观异质性源于提取噪声。仅剔除2行无法核实的研究（S013、S027）对估计值几乎无影响（k = 39，log-OR = 0.43 [0.20, 0.65]），证实这两行数据本身并非问题所在，但更广泛的数据质量隐忧依然存在。

精确n-items子集（k = 28）排除了13项分母为推算或从基准测试元数据估计的研究，得到log-OR = 0.40 [0.13, 0.67]——较全样本有所衰减。仅准确率指标子集（k = 37）排除了非准确率指标（胜率、解决率），得到0.46 [0.22, 0.71]，与全样本相似。逐一剔除分析显示合并估计值范围为0.40（剔除Wu2025，一项高影响力异常值）至0.48；无任何单项研究的剔除会改变合并效应的方向。

4. 讨论

4.1 主要发现

多智能体LLM系统平均而言似乎优于单智能体基准线（RQ1：log-OR = 0.45），但这一陈述需要大量限定。预测区间[−0.74, 1.64]可以说是更为重要的结果：它穿越零点，意味着多智能体的优势在任何新场景中都无法保证。Cohen's h = 0.08提供了关键的上下文——在绝对尺度上，这一"优势"大约相当于每100道基准测试题多答对3–5题。对于许多应用场景而言，这可能不足以证明增加的基础设施复杂性和推理成本是合理的。

Egger检验（p = .024）表明该估计值可能因小研究效应或发表偏倚而被高估。显示多智能体系统正结果的小样本研究比显示零结果的小样本研究更容易出现在我们的样本中。这种不对称性是元分析中的常见威胁，结合其他弱点，意味着真实的平均效应可能小于0.45——甚至可能大幅缩小。

4.2 多智能体何时可能有效？

亚组分析提示了一种模式，但并非因果结论。代码生成（log-OR = 0.83）可能受益于软件工程固有的模块化特性：生成代码、编写测试、审查和调试可以映射到不同的智能体角色（Hong等人，2023；Zhang等人，2024）。医学推理（log-OR = 0.42）可能受益于对抗性验证，即第二个智能体质疑第一个智能体的诊断（Tang等人，2024）。通用知识未显示获益（log-OR = 0.02）。然而，这些亚组差异与计算分配、骨干模型和研究质量等因素相混杂。显著的Qbetween值（任务：197.56；架构：32.75）表明亚组间存在异质性，但并不能确定任务类型或架构类型因果性地调节了效应。

4.3 计算混杂

在计算等价条件下，效应缩减约31%（从0.45降至0.31），Cohen's h变得可忽略不计（约0.05）。这是最具实践意义的发现。消耗单智能体5倍token的多智能体辩论，应当与在思维链、自一致性或重复采样下给予同等token预算的单智能体进行比较（Sprague等人，2024；Zhang等人，2025）。多智能体优势在计算均衡后仅勉强存活，其置信区间几乎触及零点（[0.006, 0.61]），且绝对效应量极小，这从根本上削弱了将多智能体协同作为通用策略的实践论据。对于结构化智能体间通信能够提供超越单纯计算扩展的真正信息价值的特定可分解任务，多智能体方法可能仍有其合理性。

4.4 局限性

数据质量局限。第一，本研究为探索性便利样本元分析，并非注册的系统综述。65篇因无可提取数据而被排除的记录可能并非随机缺失（附录D）。第二，Egger检验显著（p = .024），提示发表偏倚或小研究效应可能推高了合并估计值。第三，61%的研究为高偏倚风险（主要因计算资源未控制），41行中仅10行经过独立核实（76%未核实），且已审计的12行中错误率达50%。第四，I² = 96.1%极高；合并均值作为点预测几乎没有意义。第五，指标异质性（准确率、pass@1、胜率、解决率）意味着对数优势比模型假设的同质性高于底层数据实际所提供的。

分析方法局限。第六，效应量间的依赖性未经正式建模；若要进行严格推断，需采用稳健方差估计（Hedges等人，2010）或多层次模型（Van den Noortgate等人，2013）。第七，所有亚组分析均为探索性的，且未对多重比较进行校正。第八，元回归中无调节变量显著，但检验力不足。第九，多智能体与单智能体条件之间的实际计算比率很少被报告，限制了我们精确量化该混杂因素的能力。

5. 结论

本探索性元分析发现了一个积极但脆弱的信号，表明多智能体LLM协同可能优于单智能体基准线（合并log-OR = 0.45，95% CI [0.23, 0.67]；Cohen's h = 0.08；近似RD = 3–5个百分点）。然而，该证据受到以下因素的严重削弱：(1) 显著的发表偏倚（Egger p = .024），(2) 极端的异质性（I² = 96.1%，预测区间穿越零点），(3) 极小的绝对效应量，(4) 普遍的计算混杂，以及(5) 薄弱的数据溯源（76%未核实，已审计行中50%的校正率）。

最诚实的解读是：多智能体协同可能对可分解、可验证的任务（代码生成、医学推理）在计算资源充裕时有所帮助，但现有证据基础因发表偏倚、计算混杂和数据质量问题的污染程度过高，不足以做出强有力的断言。在计算等价条件下，效应在统计上仅为边界显著，绝对值可忽略不计（h ≈ 0.05）。该领域迫切需要：(a) 计算资源控制的比较（41项中仅9项实施了计算等价），(b) 独立的数据提取审计，以及(c) 带有预定义调节变量的注册元分析。在此之前，从业者应在假设协同增值之前，将任何多智能体系统与经过适当扩展的单智能体基准线进行对标。

附录E：Cohen's h作为辅助效应量

Cohen's h = 2 arcsin(√pMA) − 2 arcsin(√pSA)提供了一种绝对尺度的效应量，相比对数优势比，它对基础率膨胀的敏感度较低。在高准确率区域（例如两个条件均>90%准确率时），较小的比例差异会产生较大的log-OR但较小的h值。Cohen's h的参考标准：0.20 = 小效应，0.50 = 中等效应，0.80 = 大效应（Cohen，1988）。
