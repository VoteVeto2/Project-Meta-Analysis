多智能体是否带来更好的结果？多智能体与单智能体大语言模型系统的元分析

Xinyu Yang (r1020926)
KU Leuven，心理与教育科学学院
元分析（G0B75a），2025–2026学年
2026年5月22日 — 第4版（终稿，小修后定稿）

摘要

本探索性便利样本元分析综合了41项研究内比较（2023–2026），考察多智能体大语言模型 (LLM) 协作与单智能体提示在基准准确率上的差异。在采用REML随机效应模型并进行完整的Hartung-Knapp-Sidik-Jonkman调整后，合并对数优势比 (log-OR) 为0.45，95% 置信区间 [0.23, 0.67]，p < .001（OR = 1.57；近似风险差 ≈ 3–5个百分点）。然而，该估计值并不稳健。异质性极高（I² = 96.1%，Q(40) = 1016.6），95%预测区间跨越零值（[−0.74, 1.64]），Egger检验检测到显著的漏斗图不对称（p = .024），且总体Cohen's h极小（h = 0.08）。在计算平等条件下（k = 9），效应减弱至log-OR = 0.31（h ≈ 0.05，可忽略不计）。元回归中无调节变量达到显著水平（QM(8) = 5.34, p = .72; R² = 0%）。亚组分析表明效应可能集中于代码生成任务和层级架构，但组间检验（任务类别：Qbetween(5) = 197.56, p < .001；架构类型：Qbetween(4) = 32.75, p < .001）因未控制的混杂因素应谨慎解读。鉴于61%的研究被评为高偏倚风险、71%的提取数据未经审核，且存在发表偏倚证据，这些发现具有临时性和假设生成性质。多智能体协作在可分解任务和充裕计算预算下可能有所助益，但当前证据基础污染程度过高，不足以支持强因果断言。

1. 引言

大语言模型的多智能体范式基于一个直观的类比：正如人类团队在复杂任务上优于个体，多个LLM实例通过结构化协议进行协作，理应超越单一实例的表现。AutoGen（Wu et al., 2023）、MetaGPT（Hong et al., 2023）和ChatDev（Qian et al., 2024）等框架现已能够在层级结构、辩论机制和协作工作流中协调数十个专业化智能体。

然而，一种持怀疑态度的反叙事已经出现。Sprague et al. (2024)指出，一旦计算资源被均等化，多智能体的优势大部分会消失——多智能体系统消耗更多的推理token，而扩展单智能体的采样预算可能就能匹配多智能体的性能。Zhang et al. (2025)直接证明，在等量token预算下，单智能体基线往往能够匹配甚至超越多智能体辩论。随着前沿模型的不断改进，协调开销可能会超过递减的边际收益。

迄今尚无元分析对这些相互矛盾的发现进行综合。各研究在架构（辩论 vs. 层级 vs. 协作）、任务领域（代码 vs. 医学 vs. 数学）、骨干模型以及是否实施计算平等方面存在差异。这种异质性使得叙述性综述不可靠。我们提出四个研究问题：

研究问题1（主要）。多智能体LLM系统在基准准确率上是否优于单智能体基线？
研究问题2（计算平等）。在匹配计算预算条件下，多智能体优势是否仍然存在？
研究问题3（前沿悖论）。随着单智能体基线准确率的提高，协作增益是否缩小？
研究问题4（调节变量）。哪些任务和架构特性预测效应方向？

2. 方法

2.1 检索策略与局限

我们部署了六个并行检索智能体，分别覆盖不同的主题群组：多智能体辩论、协作/层级架构、软件工程与代码生成、医学/科学推理、批判性与零结果文献，以及前沿模型比较。每个智能体检索了arXiv、ACL Anthology、NeurIPS/ICML/ICLR会议论文集和Google Scholar，目标文献发表于2023–2026年。初步检索获得153条记录。检索词详见附录C。

重要说明：本研究为便利样本，非预注册的系统综述。未预注册任何方案。检索策略虽然广泛，但无法保证穷尽覆盖。六智能体检索方法引入了与手工系统检索不同（但未必更优）的选择偏倚。结果应视为假设生成性质。

2.2 筛选与纳入标准（PICOS）

研究对象：2023–2026年的LLM实证研究。干预：任何多智能体协作（辩论、协作、层级、角色扮演、验证-批评、混合智能体、规划-执行）。对照：使用相同骨干模型的单智能体基线。结局：基于命名基准的准确率或成功率比例。研究设计：研究内直接对比。

排除标准：经典多智能体强化学习、无实证结果的立场论文、缺乏单智能体对照的研究，以及仅含仿真评估的研究。去重（去除26条）和PICOS筛选（排除21条）后，剩余106条记录。其中41条报告了可提取的多智能体和单智能体条件下的准确率数据。被排除的65条记录编录于附录D。筛选由作者在AI辅助下完成，未计算正式的评审者间信度，这是一项局限。

2.3 效应量

我们以对数优势比 (log-OR) 作为主要效应量。仅对含零单元格的研究有条件地应用0.5连续性校正（Sweeting et al., 2004）；本分析中无此类情况。对于每项研究，我们提取了n-items（基准测试总题数）、多智能体条件下的正确数和单智能体条件下的正确数。当n-items无法直接提取时，根据报告的百分比和基准总量进行估算；41项研究中有18项被标记为估算值。Cohen's h作为辅助效应量以提供绝对量表的参照（详见附录E）。

风险差近似值。为便于实际解读，我们在报告log-OR的同时报告了近似风险差（RD = pMA − pSA）。全部41项研究的合并RD约为3–5个百分点，即多智能体系统平均每100题多解答约3–5题。在计算平等条件下，该差值缩小至约2个百分点。

指标异质性。41项比较包括准确率、pass@1、胜率、可执行性评分和解决率。我们将所有指标视为二项比例处理，但承认这一合并是一种简化。基于胜率的基准（如AlpacaEval）与项目级准确率的假设不同；解读结果时应注意此局限。

2.4 统计模型

主要分析采用限制性最大似然（REML）随机效应模型（Viechtbauer, 2005），并进行完整的Hartung-Knapp-Sidik-Jonkman（HKSJ）调整（Hartung & Knapp, 2001；IntHout et al., 2014）。HKSJ调整对合并方差估计应用缩放因子，并使用t(k−1)自由度计算合并估计的置信区间。预测区间依据IntHout et al. (2016)使用t(k−2)。DerSimonian-Laird估计作为敏感性检验。Cochran's Q使用固定效应权重和固定效应合并均值计算，产生在不同方差估计量间一致的Q值（Borenstein et al., 2009，第16章）。

亚组分析对每个水平使用独立的随机效应模型，Qbetween通过Q分解法计算（Qbetween = Qtotal − ΣQwithin；Borenstein et al., 2009，第19章）。元回归采用混合效应模型，使用条件REML τ²估计和Knapp-Hartung t分布推断，报告综合QM检验（Viechtbauer, 2010）。逐一剔除法敏感性分析在每次迭代中重新估计τ²。

依赖性。多个效应量有时来源于同一篇论文、同一基准族或同一模型族。本版本中我们未实施稳健方差估计（Hedges et al., 2010；Pustejovsky & Tipton, 2022）或多层元分析（Van den Noortgate et al., 2013）。非聚合敏感性分析（k = 36）部分缓解但未根本解决此局限。

2.5 偏倚风险

我们改编了ROB 2.0框架（Sterne et al., 2019），评估领域包括选择偏倚、执行/计算平等偏倚、报告偏倚和失访偏倚。41项研究中有25项（61%）被评为高偏倚风险，主要原因是计算资源未受控制：多智能体系统通常消耗更多推理token，却未进行任何单智能体扩展对比。此外，41项研究中有29项（71%）的数据提取准确性尚未审核，尽管已审核的12行中有50%的纠错率。

2.6 发表偏倚

使用k = 41进行了漏斗图检查、Egger回归检验（Egger et al., 1997）、Begg秩相关（Begg & Mazumdar, 1994）、Duval和Tweedie的剪补法（Duval & Tweedie, 2000）以及p-curve分析（Simonsohn et al., 2014）。

3.2 描述性特征

纳入的41项比较涵盖2023–2026年。占主导地位的架构类型为辩论（k = 20，49%），其次为协作（k = 9）、层级（k = 6）、验证-批评（k = 2）和角色扮演（k = 2），另有一项混合智能体研究和一项规划-执行研究。任务类别包括代码生成（k = 11）、"其他"混合基准（k = 10）、医学推理（k = 7）、数学（k = 6）、评估任务（k = 3）、通用知识（k = 3）和事实性（k = 1）。骨干模型涵盖GPT-4系列、Claude、Gemini、Qwen及开源模型。41项研究中有18项的n-items为估算值（非直接提取）。仅9项研究在多智能体和单智能体条件之间实施了计算平等。

REML模型得到合并log-OR为0.45（95%置信区间 [0.23, 0.67]，p < .001），对应OR = 1.57。然而在绝对量表上，总体Cohen's h为0.08——远低于"小"效应的0.20阈值（Cohen, 1988）。近似风险差为3–5个百分点，意味着多智能体系统在每100道基准题目中大约多解答3–5题。这是否足以证明增加的复杂性和计算成本合理，是一个系统设计问题，而非统计问题。

关键警示：多重威胁削弱了该估计。合并效应为正但脆弱： （1）预测区间 [−0.74, 1.64] 跨越零值，因此新研究完全可能发现单智能体更优。 （2）Egger检验显著（p = .024），表明漏斗图不对称及可能的发表偏倚或小样本效应。 （3）Cohen's h = 0.08在绝对量表上属微不足道。 （4）61%的研究为高偏倚风险，71%的数据未经审核。 （5）I² = 96.1%意味着"平均效应"作为点预测几乎毫无意义。 诚实的解读是：这是一个正向但临时性的信号，而非稳健的发现。

3.4 异质性

异质性极高：I² = 96.1%，Q(40) = 1016.6（p < .001），τ² = 0.34，τ = 0.58。研究间标准差（τ = 0.58）超过了合并估计值本身（0.45），证实真实效应的分布范围很广。合并均值不应作为任何特定情境下的点预测。

组间Q检验高度显著（Qbetween(5) = 197.56, p < .001），表明任务类别与效应量变异相关。Q分解法假设各亚组间具有共同的τ²；鉴于组内I²从0%到99.7%不等，该假设可能被违反。代码生成产生了最大的多智能体效应（log-OR = 0.83），这与模块化、可分解任务有利于智能体专业化的直觉一致（Hong et al., 2023；Zhang et al., 2024）。医学推理呈现中等效应（log-OR = 0.42），可能反映了对抗性验证的价值——第二个智能体质疑第一个的诊断（Tang et al., 2024）。通用知识几乎没有获益（log-OR = 0.02），表明对于简单的事实检索，协调只会增加噪声。然而，这些亚组估计与计算资源分配、骨干模型和研究质量存在混杂；表面上的任务梯度可能部分反映了这些相关因素。k < 3的亚组标记为"仅描述性"——其τ²估计不具参考价值（Borenstein et al., 2009，第17章）。

发表偏倚现已成为一项关注。Egger回归检验（对截距进行检验）显著（截距 = 2.53, t(39) = 2.34, p = .024）。这表明漏斗图不对称与小样本效应一致——样本中较小的研究倾向于显示更大的正效应。这种模式是发表偏倚的典型特征（小规模正结果研究被发表，而小规模零结果研究未被发表），或与研究规模相关的真正异质性。Begg检验和剪补法未达显著，但这些方法对连续结局的灵敏度低于Egger检验。P-curve显示右偏（25/28项显著结果），但p-curve假设独立、同质的假设检验——此处仅近似满足这些条件。总体而言，正向的合并估计可能因选择性报告而被夸大，这实质性地削弱了主要发现。

最具实质意义的敏感性分析是计算平等（k = 9）：仅纳入均等化推理token的研究后，合并log-OR从0.45降至0.31（衰减约31%）。置信区间下限勉强超过零值（未四舍五入值：[0.004, 0.57]），对应的Cohen's h约为0.05——按常规标准可忽略不计。这意味着在公平计算比较条件下，多智能体系统每100道基准题目大约多答对2题，该效应在统计上处于临界水平，在实际意义上微不足道。

仅已验证子集（k = 10）的估计明显低于全样本：log-OR = 0.35 [0.19, 0.51]，异质性大幅降低（τ² = 0.01 vs. 0.34）。较低的点估计值是一个警示：29项未审核的研究可能包含提取错误，从而夸大了合并效应。τ²的降低表明，全样本中部分表观异质性源于提取噪声。仅审核了12行且纠错率高达50%，"令人放心"一词过于乐观。仅已验证的结果更为可信，但鉴于k值较小，也不应过度解读。

精确n-items子集（k = 28）排除了13项使用估算分母的研究，得到log-OR = 0.40 [0.13, 0.67]——较全样本有所衰减。仅准确率子集（k = 37）排除了非准确率指标（胜率、可执行性评分），得到0.46 [0.22, 0.71]，与全样本相近。

4. 讨论

4.1 主要发现

多智能体LLM系统在平均水平上似乎优于单智能体基线（研究问题1：log-OR = 0.45），但这一陈述需要大量限定。预测区间 [−0.74, 1.64] 可以说是更为重要的结果：它跨越零值，意味着对于任何新情境，多智能体的优势并非确定无疑。Cohen's h为0.08提供了关键背景——在绝对量表上，这种"优势"相当于每100道基准题目多答对约3–5题。对于许多应用场景，这可能不足以证明增加的基础设施复杂性和推理成本合理。

Egger检验（p = .024）表明该估计很可能被小样本效应或发表偏倚所夸大。显示多智能体系统正面结果的小规模研究，比显示零结果的小规模研究更可能出现在我们的样本中。这种不对称性是元分析中的标准威胁，结合其他弱点，意味着真实的平均效应可能小于0.45——甚至可能大幅缩小。

4.2 多智能体在何种情况下可能有效？

亚组分析提示了一种模式，但并非因果结论。代码生成（log-OR = 0.83）可能获益更多，因为软件工程本质上是模块化的：代码生成、测试编写、审查和调试可以映射到不同的智能体角色（Hong et al., 2023；Zhang et al., 2024）。医学推理（log-OR = 0.42）可能受益于对抗性验证，即第二个智能体质疑第一个的诊断（Tang et al., 2024）。通用知识未显示获益（log-OR = 0.02）。然而，这些亚组差异与计算资源分配、骨干模型和研究质量混杂。显著的Qbetween值（任务：197.56；架构：32.75）表明亚组间存在异质性，但不能证明任务类型或架构类型因果性地调节了效应。

4.3 计算混杂

在计算平等条件下，效应缩小约31%（从0.45降至0.31），Cohen's h变为可忽略不计（约0.05）。这是最具实践意义的发现。消耗5倍token的多智能体辩论应与同等token预算下采用思维链、自一致性或重复采样的单智能体进行比较（Sprague et al., 2024；Zhang et al., 2025）。多智能体优势在计算均等化后仅勉强存活——置信区间几乎触及零值（[0.004, 0.57]）且绝对效应量微不足道——这实质性地削弱了将多智能体协作作为通用策略的实际论据。它可能仍适用于特定的可分解任务，在这些任务中结构化的智能体间通信能够提供超越单纯计算扩展的真正信息价值。

4.4 局限性

数据质量局限。第一，这是一项探索性便利样本元分析，而非预注册的系统综述。65条无可提取数据的排除记录可能并非随机缺失（附录D）。第二，Egger检验显著（p = .024），表明发表偏倚或小样本效应可能夸大了合并估计。第三，61%的研究为高偏倚风险（主要因计算资源未控制），71%的数据尚未审核，尽管已审核行的纠错率高达50%。第四，I² = 96.1%为极端异质性；合并均值作为点预测几乎毫无意义。第五，指标异质性（准确率、pass@1、胜率、解决率）意味着log-OR模型假设了比实际数据更高的同质性。

分析方法局限。第六，效应量间的依赖性未正式建模；稳健方差估计（Hedges et al., 2010）或多层建模（Van den Noortgate et al., 2013）是严格推断所必需的。第七，所有亚组分析均为探索性，未对多重比较进行校正。第八，元回归中无调节变量显著，但回归统计效力不足。第九，多智能体和单智能体条件之间的实际计算比率很少被报告，限制了我们精确量化混杂程度的能力。

5. 结论

本探索性元分析发现了一个正向但脆弱的信号，表明多智能体LLM协作可能优于单智能体基线（合并log-OR = 0.45，95%置信区间 [0.23, 0.67]；Cohen's h = 0.08；近似RD = 3–5个百分点）。然而，该证据受到以下因素的实质性削弱：（1）显著的发表偏倚（Egger p = .024），（2）极端异质性（I² = 96.1%，预测区间跨越零值），（3）微不足道的绝对效应量，（4）普遍的计算混杂，以及（5）薄弱的数据来源（71%未审核，已审核行中50%的纠错率）。

最诚实的解读是，多智能体协作可能对可分解、可验证的任务（代码生成、医学推理）在充裕计算预算下有所助益，但当前证据基础因发表偏倚、计算混杂和数据质量问题而严重受损，不足以做出强因果断言。在计算平等条件下，效应在统计上处于临界显著，在绝对量上可忽略不计（h ≈ 0.05）。该领域亟需：（a）计算受控的比较（41项中仅9项实施了平等），（b）独立的提取审核，（c）预注册的元分析并预设调节变量。在此之前，实践者在假设协作能增加价值之前，应将任何多智能体系统与适当扩展的单智能体基线进行基准比较。

附录E：Cohen's h作为辅助效应量

Cohen's h = 2 arcsin(√pMA) − 2 arcsin(√pSA)提供了一个绝对量表的效应量，相比log-OR对基础率膨胀的敏感性更低。在高准确率区间（如两个条件均>90%准确率），较小的比例差异会产生较大的log-OR但较小的h。Cohen's h基准：0.20 = 小效应，0.50 = 中等效应，0.80 = 大效应（Cohen, 1988）。

表E1. 关键分析的合并Cohen's h。
分析kCohen's h解读
全样本410.08微不足道（低于"小"效应阈值）
代码生成110.14微不足道至小效应
仅计算平等9≈ 0.05可忽略不计
医学推理70.09微不足道
通用知识30.00无效应

启示。看似令人鼓舞的log-OR（0.45，OR = 1.57）与微不足道的Cohen's h（0.08）之间的差异值得重视。log-OR在高准确率区间会被放大，在这些区间中两个条件均接近天花板。许多纳入的研究处于此类区间（如单智能体准确率>80%），这意味着57%的优势比增幅仅转化为每100题约3–5题的额外正确数。在计算平等条件下，这进一步缩小至每100题约2题（h ≈ 0.05）。实践者在做出部署决策时，应基于绝对增益而非优势比来评估多智能体系统。
