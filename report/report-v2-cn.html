更多智能体，更好的结果？多智能体与单智能体大语言模型系统的元分析

Xinyu Yang (r1020926)
鲁汶大学 (KU Leuven)，心理与教育科学学院
元分析 (G0B75a)，2025–2026学年
2026年5月22日 — 修订版2（同行评审后）

摘要

本探索性便利样本元分析综合了41项研究内比较（2023–2026），考察多智能体大语言模型（LLM）协作（辩论、合作、层级委派）相较于单智能体提示在基准测试准确率上的表现。在采用REML随机效应模型及Knapp-Hartung调整的条件下，合并对数优势比（log-OR）倾向于多智能体系统（log-OR = 0.45, 95% 置信区间 [0.25, 0.65], p < .001），对应小到中等的优势（OR = 1.57）。异质性极高（I² = 96.1%, τ² = 0.34, Q(40) = 1016.6），且95%预测区间跨越零值（[−0.74, 1.64]），表明新研究完全可能发现单智能体具有优势。亚组分析表明，该优势集中在代码生成任务（log-OR = 0.83）和层级架构（log-OR = 0.76），而通用知识任务未显示任何获益（log-OR = 0.02）。在计算平等条件下（k = 9），效应量衰减为log-OR = 0.31 [0.04, 0.57]。仅限已验证研究的敏感性分析（k = 12：log-OR = 0.45 [0.26, 0.64]）和非聚合基准测试（k = 36：log-OR = 0.48 [0.24, 0.72]）证实了主要发现。以基线单智能体准确率作为前沿悖论代理变量的元回归发现方向一致但不显著的效应（β = −0.77, t(32) = −1.38, p = .176）。发表偏倚诊断（Egger检验 p = .77；p曲线：28个显著结果中25个呈右偏，p < .001）表明存在真实的证据价值。作为未注册的便利样本，这些发现应被视为假设生成而非验证性结论。

1. 引言

大语言模型的多智能体范式建立在一个直觉性的类比之上：正如人类团队在复杂任务上的表现优于个人，多个LLM实例通过结构化协议进行协作应当超越单一实例的表现。这一直觉推动了该范式的快速普及。AutoGen（Wu et al., 2023）、MetaGPT（Hong et al., 2023）和ChatDev（Qian et al., 2024）等框架目前可在层级结构、辩论和合作工作流中协调数十个专业化智能体。

然而，一种质疑性的反叙事已经出现。Sprague et al. (2024)和Chen et al. (2025)指出，一旦计算量被均衡化，观察到的多智能体优势大部分将消失——多智能体系统只是消耗了更多的推理token。Lu et al. (2024)证明，扩展单智能体的采样预算即可匹配甚至超过多智能体辩论。此外，随着前沿模型的不断进步——Claude Opus 4.5、GPT-4o、Gemini 2.5——协调开销可能超过递减的边际收益（Anthropic, 2025）。

迄今尚无元分析对这些相互矛盾的发现进行综合。个体研究在架构（辩论 vs. 层级 vs. 合作）、任务领域（代码 vs. 医学 vs. 数学）、骨干模型以及是否实施计算平等方面存在差异。这种异质性使得叙述性综述不够可靠。我们提出四个研究问题：

RQ1（主要）。多智能体LLM系统在基准测试准确率上是否优于单智能体基线？
RQ2（计算平等）。在匹配的计算预算下，多智能体优势是否仍然成立？
RQ3（前沿悖论）。随着基线单智能体准确率的提高，协作增益是否缩小？
RQ4（调节变量）。哪些任务和架构属性能预测效应方向？

2. 方法

2.1 检索策略

我们部署了六个并行搜索智能体，覆盖不同的主题领域：多智能体辩论、合作/层级架构、软件工程与代码生成、医学/科学推理、批评性和零效应文献，以及前沿模型比较。每个智能体检索arXiv、ACL Anthology、NeurIPS/ICML/ICLR会议论文集和Google Scholar上2023–2026年发表的论文。所有智能体共检索到153条记录。

2.2 筛选与纳入（PICOS）

人群：2023–2026年LLM实证研究。干预：任何多智能体协作（辩论、合作、层级、角色扮演、验证-评论、混合智能体、规划-执行）。对照：使用相同骨干模型的单智能体基线。结局：命名基准测试上的准确率或成功率比例。研究设计：研究内头对头比较。

排除标准：经典多智能体强化学习、无实证结果的立场论文、缺乏单智能体对照的研究以及仅模拟评估的研究。经去重（剔除26篇）和PICOS筛选（排除21篇）后，剩余106条记录。其中41项研究报告了多智能体和单智能体条件下可提取的准确率数据。

2.3 效应量

我们以对数优势比（log-OR）作为主要效应量。仅对含零单元格的研究有条件地应用0.5连续性校正（Sweeting et al., 2004）。在本样本中，没有研究包含零单元格，因此未应用校正。对于每项研究，我们提取了n-items（基准测试总题目数）、多智能体条件下的正确数和单智能体条件下的正确数。在n-items无法直接提取时，根据报告的百分比和基准测试总量进行估算；41项研究中有18项在数据文件中被标记为估算值。Cohen's h作为次要效应量计算，结果见附录C。

2.4 统计模型

主要分析采用限制最大似然（REML）随机效应模型（Viechtbauer, 2005），并使用Hartung-Knapp-Sidik-Jonkman（HKSJ）调整计算置信区间（Hartung & Knapp, 2001；IntHout et al., 2014）。置信区间使用t(k−2)而非z = 1.96。预测区间遵循IntHout et al. (2016)的方法，使用t(k−2)。DerSimonian-Laird估计作为敏感性检验。Cochran's Q采用固定效应权重和固定效应均值计算，产生的Q值在不同估计方法间保持一致（Borenstein et al., 2009，第16章）。

亚组分析对每个水平使用独立的随机效应模型，组间Q通过Q值分解法计算（Qbetween = Qtotal − ΣQwithin；Borenstein et al., 2009，第19章）。元回归采用混合效应模型，条件REML τ²估计及Knapp-Hartung t分布推断，报告综合QM检验（Viechtbauer, 2010）。逐一剔除敏感性分析在每次迭代中重新估计τ²。

2.5 偏倚风险

我们改编了ROB 2.0框架（Sterne et al., 2019），涵盖选择、表现/计算平等、报告和失访等领域。每项研究被评定为"低风险""存在一定关注"或"高风险"。最常见的高风险来源是未控制的计算量：多智能体系统通常消耗3至10倍以上的推理token，而没有任何单智能体扩展比较。

2.6 发表偏倚

对k = 41项研究进行了漏斗图检查、Egger回归检验（Egger et al., 1997）、Begg秩相关检验（Begg & Mazumdar, 1994）、Duval和Tweedie剪补法（Duval & Tweedie, 2000）以及p曲线分析（Simonsohn et al., 2014）。

3.2 描述性特征

纳入的41项比较涵盖2023–2026年。主要架构为辩论（k = 20，49%），其次为合作（k = 9）、层级（k = 6）、验证-评论（k = 2）和角色扮演（k = 2），以及各一项混合智能体和规划-执行研究。任务类别包括代码生成（k = 11）、"其他"混合基准测试（k = 10）、医学推理（k = 7）、数学（k = 6）、评估任务（k = 3）、通用知识（k = 3）和事实核查（k = 1）。骨干模型涵盖GPT-4系列、Claude、Gemini、Qwen及开源模型。41项研究中有18项的n-items值为估算值（而非直接提取）。

REML模型产生的合并log-OR为0.45（95%置信区间 [0.25, 0.65]，p < .001），代表多智能体系统具有小到中等的优势。转换为优势比（e0.45 = 1.57），多智能体系统平均正确回答的几率约高出57%。

关键发现：预测区间跨越零值。95%预测区间 [−0.74, 1.64] 意味着从该设定总体中抽取的新研究可能合理地显示单智能体优势。在I² = 96.1%的情况下，0.45的"平均效应"虽然真实存在，但作为点预测几乎没有意义。该效应并非多智能体系统的稳定属性——它在很大程度上取决于什么任务、什么架构以及多少计算量被分配。

3.4 异质性

异质性极高：I² = 96.1%，Q(40) = 1016.6（p < .001），τ² = 0.34，τ = 0.58。研究间标准差（τ = 0.58）超过合并估计值本身（0.45），证实真实效应的分布范围很广。这要求进行亚组分析和元回归分析，而非仅依赖合并均值。

在α = .05水平上没有调节变量达到显著，综合QM检验亦不显著（QM(8) = 5.42，p = .712）。单智能体准确率系数（β = −0.77，t(32) = −1.38，p = .176）在实质意义上最为重要：其负方向与前沿悖论假说（RQ3）一致——随着单智能体基线增强，多智能体协作的边际收益缩小——但在当前样本量下该效应不具有统计可靠性。用直接的基线准确率替代先前使用的"年份"代理变量，为前沿悖论机制提供了更有效的检验，尽管结果仍不确定。

发表偏倚诊断结果令人放心。Egger检验（p = .77）和Begg检验（p = .61）未检测到漏斗图不对称性。剪补法填补零项缺失研究。p曲线——28个显著结果中25个呈右偏（89%，二项检验p < .001）——表明存在真实的证据价值而非p值操纵（Simonsohn et al., 2014）。漏斗图不对称性的缺失可能部分归因于我们刻意纳入了"批评性文献"搜索智能体（第5个智能体），该智能体检索到的零效应和负效应发现抵消了正结果的发表偏倚。

计算平等敏感性分析（k = 9）是最具实质意义的：限制为均衡化推理token的研究后，合并log-OR从0.45降至0.31——衰减约31%。效应仍然显著（95%置信区间 [0.04, 0.57]），表明多智能体协作提供的价值超越了纯粹的计算量扩展，但未控制的计算混杂确实放大了朴素估计值。剔除高偏倚风险研究（k = 16）产生几乎相同的点估计（log-OR = 0.42），2025年及之后子集（k = 29）也保持一致（log-OR = 0.41）。

两项新的敏感性分析回应了数据质量方面的关注。仅已验证子集（k = 12）限定为提取数据经过独立审核的研究，产生log-OR = 0.45 [0.26, 0.64]，异质性大幅降低（τ² = 0.05，全样本为0.34）。与全样本估计值的高度吻合令人放心，尽管降低的τ²表明全样本中的部分异质性源于提取噪声而非真实的研究间差异。非聚合子集（k = 36）排除了跨多个基准测试取平均值的研究，产生log-OR = 0.48 [0.24, 0.72]——略高于全样本，表明聚合基准测试研究（如果有影响的话）反而衰减了估计值。

总体证据确定性：低。正向的合并效应可能是真实的（发表偏倚诊断干净，且效应经受住多项敏感性分析的检验），但由于极端的异质性和普遍的计算混杂，在任何特定场景中的真实效应高度不确定。作为未注册的便利样本，这些发现属于假设生成性质。

5. 讨论

5.1 主要发现

多智能体LLM系统在平均水平上确实优于单智能体基线（RQ1：log-OR = 0.45，p < .001），但这一表述需要立即加以限定。预测区间 [−0.74, 1.64] 才是核心发现，而非合并均值。它告诉从业者，"平均优势"是对根本不同的设定进行平均的统计产物。对于任何特定的部署场景，预期效应从中等程度的劣势到大幅优势不等，具体取决于任务、架构和计算量分配。

5.2 多智能体何时有效？

亚组分析提供了可操作的指导。代码生成（log-OR = 0.83）获益最大，这可能是因为软件工程本质上是模块化的：生成代码、编写测试、审查和调试自然地映射到不同的智能体角色（Qian et al., 2024；Zhang et al., 2024）。层级架构（log-OR = 0.76）与此模式一致——明确的任务分解和委派利用了同样的模块化特性。医学推理（log-OR = 0.42）受益于对抗性验证，即第二个智能体质疑第一个智能体的诊断（Tang et al., 2024；Xiong et al., 2024）。

相反，通用知识问答（log-OR = 0.02）未获得任何收益。当问题在模型的参数知识中有唯一的事实答案时，增加智能体只会带来协调成本而无新信息。无结构的合作（log-OR = 0.31，置信区间跨越零值）表现类似——无结构的多智能体交互往往退化为回音室或迎合性一致（Du et al., 2023；Liang et al., 2024）。

5.3 计算混杂与前沿悖论

在计算平等条件下，效应缩小约31%（从0.45降至0.31）。这是对系统设计者而言最具实践意义的发现。消耗5倍token的多智能体辩论不应与单次调用进行比较，而应与给予相同token预算（通过思维链、自一致性或重复采样）的单智能体进行比较（Sprague et al., 2024；Lu et al., 2024）。即使在此调整之后，多智能体优势依然存在（log-OR = 0.31，p < .05），表明结构化的智能体间通信具有真正的涌现价值——但从业者应预期比标题数字所暗示的更小的收益。

前沿悖论假说（RQ3）——多智能体收益随基线模型增强而缩小——获得了方向一致但不确定的支持。用基线单智能体准确率替代先前使用的"年份"代理变量产生β = −0.77（t(32) = −1.38，p = .176）。负号与该假说一致：单智能体准确率每增加一个单位，log-OR减少0.77。然而，在k = 41的条件下，元回归的统计效力不足以检测此量级的调节效应。随着前沿模型持续改进，该问题仍然悬而未决且具有紧迫的实践意义。

5.4 对从业者的启示

智能体编码系统的兴起——Claude Code（Anthropic, 2025）、Cursor、Devin——重新塑造了这一讨论。这些工具在单智能体界面中嵌入了多智能体模式（规划、执行、验证），使得多智能体与单智能体的区分变得模糊。我们发现层级架构和代码任务显示最大效应，这与这些工具的设计选择一致：它们之所以成功，正是因为软件工程具有使多智能体协作物有所值的任务属性（可分解性、可验证性、模块化性）。

5.5 局限性

第一，这是一项探索性便利样本元分析，而非注册的系统综述。我们的六智能体搜索策略虽然广泛，但无法保证穷尽覆盖，且因缺乏可提取数据而排除的65项研究可能并非随机缺失。第二，样本量（k = 41）限制了元回归的统计效力；QM不显著不应被解释为无调节效应的证据。第三，I² = 96.1%即使按社会科学标准也属极端，尽管我们探索了调节变量，仍有大量未解释的异质性。第四，61%的研究被评为高偏倚风险，主要是由于未控制的计算量——这是整个领域而非仅限于本样本的方法学弱点。第五，41项研究中有18项的n-items计数为估算而非直接提取，尽管仅已验证研究的敏感性分析（k = 12）以大幅降低的异质性（τ² = 0.05）证实了主要发现。第六，我们未通过稳健方差估计对同一篇论文中多个效应量的依赖性进行建模（Hedges et al., 2010；Pustejovsky & Tipton, 2022）；非聚合敏感性分析（k = 36）部分解决了这一问题。第七，所有亚组分析均为探索性的，未对多重性进行校正。

5.6 完整系统综述将增加的价值

一项具有注册方案的系统综述——由多名独立编码员参与、检索灰色文献并联系原始作者——将增强对估计值的信心。预注册的调节变量分析将解决我们探索性亚组检验中的多重比较问题。稳健方差估计（Hedges et al., 2010）或多层次元分析（Van den Noortgate et al., 2013）将允许每项研究纳入多个效应量而不膨胀第一类错误率。

6. 结论

本探索性便利样本元分析发现，多智能体LLM协作相对于单智能体基线具有真实但不稳定的优势（合并log-OR = 0.45，95%置信区间 [0.25, 0.65]）。预测区间 [−0.74, 1.64] 才是真正重要的发现：它跨越零值，意味着在任何新的设定中多智能体优势并非确定的。该优势集中在代码生成（log-OR = 0.83）和层级架构（log-OR = 0.76），在通用知识问答中消失（log-OR = 0.02），并在计算平等条件下缩小31%（log-OR = 0.31）。仅已验证研究子集（k = 12）以大幅降低的异质性证实了主要估计。前沿悖论假说获得方向一致但不显著的支持（β = −0.77，p = .176）。证据的总体确定性评级为低（GRADE），原因在于普遍的偏倚风险和极端的异质性。从业者应有选择性地部署多智能体系统——用于可分解、可验证的任务，在这些任务中结构化的智能体角色能增加真实信息——并始终与适当扩展的单智能体基线进行基准测试。该领域迫切需要计算量控制的比较：41项研究中仅9项实施了平等。

全样本410.08小效应

Cohen's h基准：0.20 = 小效应，0.50 = 中效应，0.80 = 大效应（Cohen, 1988）。相对于log-OR而言较小的h值反映了许多研究处于高准确率区间，此时log-OR会放大微小的比例差异。
